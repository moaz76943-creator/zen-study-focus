DEEP FOCUS Privacy Policy

Application: DEEP FOCUS (com.moaz76943.zenfocus) | Last Updated: November 11, 2026
Zero-Data Philosophy: DEEP FOCUS operates with ZERO network permissions. It does not collect, record, track, transmit, or share any personal information, location, or usage data whatsoever.

1. Data Collection & Transmission

DEEP FOCUS is strictly an offline tool. The application:

  • Contains no network communication modules (no internet permission in the Android Manifest).
  • Does not collect names, emails, hardware IDs, IP addresses, or device fingerprints.
  • Contains zero third-party analytics libraries, advertising SDKs, or remote telemetry frameworks.

2. Local Storage and Preferences

All study intervals, active ambient sounds, language selections, and session logs are retained entirely inside your local device sandbox. Data is never synced to external cloud databases.

3. Procedural Audio Synthesis

Soundscapes such as binaural frequencies and white noise are synthesized locally in real time via the Web Audio API. No external audio streams or microphone recordings are utilized.

4. Children’s Privacy & Global Compliance

Because no personal data is collected from any user at any time, DEEP FOCUS complies comprehensively with COPPA, GDPR, and Google Play Families Policy requirements.

5. Source Code & Verification

This application's integrity can be inspected directly on our open repository: GitHub: zen-study-focus.
