# Translation glossary (meaning first)

Translate the function, not the dictionary word. Context column = where the user sees it.

| English | Context / meaning in DEEP FOCUS | Do NOT translate as |
|---|---|---|
| Focus / Focus session | A timed period of concentrated study or work | visual focus, camera focus |
| Session | One timed period (study, work, workout, review) | login session, meeting |
| Break / Rest | Pause between focus periods | broken, to break something |
| Long break | The longer pause after several focus periods | |
| Daily goal / Target | Minutes or items planned for today | life goal, sports target |
| Due / Due today | A flashcard scheduled for review now; for tasks, the deadline | money owed |
| Review (Flashcards) | Studying cards again (spaced repetition) | evaluation, product review |
| Again / Hard / Good / Easy | How well the card was recalled; Again = forgot | |
| Resume | Continue a paused timer/session | CV |
| Skip | Move past a step/rest without doing it | |
| Reset | Return the timer to its start value (no data deleted) | restart the app, factory reset |
| Stop | End playback/speech now | pause |
| Pause | Temporarily halt, can resume | stop |
| Delete | Remove permanently (may offer undo) | archive |
| Archive | Hide but keep, can be restored | delete |
| Suspend (card) | Exclude a card from reviews until unsuspended | suspend an account |
| Backup | A full copy of app data for restoring later | export of one item |
| Restore | Replace current data from a backup | import |
| Import | Add items from a file (cards, CSV) | restore |
| Export | Write items to a file to use elsewhere | backup |
| Sound / Volume | Sound = which ambient sound; Volume = loudness | |
| Streak | Consecutive days with a completed session | |
| Deck | A set of flashcards | ship deck |
| Writing mode / Type your answer | User types the answer; spelling is compared | handwriting |
| Listening mode | Card is spoken, user answers from audio | |
| Pronunciation | Device text-to-speech reads the card | pronunciation scoring (not supported) |

Never translate: Deep Focus, SVG, CSV, TSV, JSON, LaTeX, PIN, QR, HRTF, AMOLED, WPM, RSVP, Wi-Fi, P2P, Pomodoro (may be transliterated), Cornell and Feynman (may be transliterated).

High-risk buttons (wrong wording can cause data loss): Delete, Remove, Reset, Restore, Backup, Overwrite, Cancel, Confirm, Clear, Archive, Suspend, Import, Export, Stop/Pause. Reviewers must check these first in every language.
