Status: **20 planned nature choices; only forest + wind remain enabled**. This is NOT a claim that 20 audio recordings have been restored.

## Why only two play
PR #25 `app.js` deliberately allows only `forest` and `wind`. The prior 12-category catalog contains missing, synthetic or unproven files. `earth.ogg` is identical to `noise.ogg` and is an air-conditioner hum, not earth/nature. Existing nine new Ogg loops and three remaining quarantined files have unknown original-to-derivative proof and no successful real-device listening sign-off; see `docs/audio_acquisition_12/README.md` and Issue #13. Never change approval flags to make counts look better.

## Non-negotiable release blockers
1. Each **actual distributed Ogg** must be traced to an individual commercial-redistribution-compatible source and its original hash, modification chain, final hash, codec, duration and attribution where required.
2. Human listening on Android (speaker + headphones), mixed volumes, abrupt peaks, seamless loops for 30+ minutes, background / locked screen, Bluetooth, DND and audio focus must be checked. Desktop Node or ffprobe is not device acceptance.
3. No unused files concealed as playable, no remote audio streaming, no signature/manifest/storage/package changes, no direct main merge. Keep the strict existing media release gate RED until proven.
4. Review candidate CI artifact, reject any source where recording content differs from label, obtain missing source assets, then integrate approved files in small independently tested batches.

Verification: `node --test tests/nature_library_v2/catalog.test.cjs` and the pre-existing nature runtime tests. A separate lightweight GitHub Actions job performs tests and a SHA1-pinned Commons candidate intake. Release remains blocked.
